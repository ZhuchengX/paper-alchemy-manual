PAPER ALCHEMY · 使用说明书

把一堆论文，炼成一篇值得精读的论文

本机流水线：codex 跑 LLM 阶段，脚本把关，你在闸口拍板。做到哪看 进度表 与 case 现状；每个模块的完整做法看 设计细节。

这是什么

输入 N 篇论文，输出 1 篇抽象出通解的论文，让你只需精读 m 篇（m ≪ N）。不是摘要，也不是综述。

输入

一批论文，人写或 autoresearch 产出均可。按摘要、按机构筛两轮；按共享作者分独立来源组。

中间

每篇拆成「带条件的事实 ＋ 方法程序」。多个提议者各出通解，互不相读；审稿另派人逐条判。

输出

中英文论文 PDF、中文阅读页、交付包。正文每个数字都能在包里复算。

它不是一键出论文的服务，不是想题目的聊天框，也不是综述生成器。

跑第一轮

每轮一个运行目录。agent 只能读它和全文目录，读不到别的轮的结论和答案。

① 给一句话主题

python3 -I pipeline/orchestrate.py new ~/runs/run4 --topic "多次便宜调用什么时候能追上一次贵调用" \
    --split 2025-07-01 --forbid /Users/xzc/HITSZ/PaperAlchemy/cases/run3
  • 建目录、冻结脚本快照；1 个 agent 按主题起草 config/menu.md，停在 ★①。
  • --forbid：agent 不许读的目录（pipeline 目录总在内）。已有菜单：把 --topic … 换成 --from 菜单.md。

② 改菜单，然后一路回答

  • 菜单不对就直接改 config/menu.md，再回答 ★①。
  • 要评估：把锁定答案的论文编号写在 “reserved for evaluation” 后；答案文件放运行目录外。
python3 -I pipeline/orchestrate.py run ~/runs/run4 --answer ok                # 认了，跑到下一个闸
python3 -I pipeline/orchestrate.py run ~/runs/run4 --answer no:原因           # 不认，停住
python3 -I pipeline/orchestrate.py run ~/runs/run4 --answer ok --set ANSWER_KEY=/运行目录外/答案文件   # 顺带评估
python3 -I pipeline/orchestrate.py run ~/runs/run4 --fake-agent FIXTURE       # 不花钱先走一遍

★① 之后一路跑到交付包，只在 ★ 闸和出事时的 ↺ 条件闸停。改了哪个模板或脚本，只重跑用到它的阶段。

③ 离开与回来

  • 中途离开：回来再敲同一条命令，做完的跳过，断掉的重跑。
  • 成果：paper/ 下是论文 PDF；deliver/ 下是交付包和中文阅读页 reader/reader_zh.html。
菜单怎么填（范例） 
选题：多次便宜调用 vs 一次贵调用——多 agent、并行采样、投票 / 聚合、辩论、自适应停止、test-time scaling。
中心问题：多花便宜模型的 token，什么时候能追平或超过一次贵模型调用，要花多少？
读者：做 agent 系统的研究者；注意力预算：正文 ≤ 4,500 词。
时间窗：2023-01-01 .. 2026-10-19
纳入：train-free；报告了算力或成本；有受控基线。
排除：只训练策略的、单链推理、综述、没有任务准确率的。
reserved for evaluation：几篇人类后来公认结论的论文编号

中心问题要外行一分钟听懂，并说清什么算答上；审稿用它判跑没跑题。锁定答案的论文不进语料，任何 agent 都读不到，最后用来检验能否独立炼出同样结论。

它怎么思考

① 先拆后聚

剥掉包装，每篇只留带条件的事实和方法程序，在这一层找通解。例：自一致性 k=9 写成 Gen(9,cot,same); Agg(vote)。

设计原则第 3 条；config/schema.md

② 提议与裁判分开

多个提议者各出候选通解，互不相读。每条候选一个审稿人判 VALIDATED / REVISE / DROP，REVISE 最多改 2 轮；终稿只从 VALIDATED 里选，淘汰的留档。

打分用 MDL：通解短、解释事实短、能预测更晚的论文（设计原则第 4 条）· B2 · 巨人镜头

③ 每条结论都被反复敲打

按算力归一化比较；再查去掉一个来源组还成不成立、发表偏倚、矛盾对。撑不起就 KILL、不成文；有争议的只写带边界的条件陈述。

设计原则第 6、7 条 · B6

④ 成文也被机器管住

选骨架 → 写 → 查禁说 → 新眼审稿 → 每个数字找来源 → 打包，在干净沙箱复算。正文每改一版都留档。
